# EaseBiz AI — Flask Edition

An MSME compliance assistant that helps small business owners in India quickly identify the licenses, government schemes, and export requirements relevant to their business — surfaced through a dashboard with real market-analysis output, not static filler.

This is a Python/Flask rebuild of an earlier React (Vite + TypeScript) version of the app, with one key fix: the "AI Analysis" step now actually calls a live LLM, and the PDF report is generated server-side.

> **Why this exists:** the original React version shipped with a `@google/genai` dependency that was never actually called — the "AI Analyzing..." step was a 2-second fake spinner over hardcoded text. This rebuild wires up a real (and free) LLM call via **Groq** for the Market Analysis, Expert Advice, and Competition sections. License fees, timelines, and government scheme links stay as static, verified data rather than being generated by the LLM — those are facts, and an LLM shouldn't be guessing at facts.

## Features

- **Compliance lookup** — surfaces relevant licenses, government schemes, and export requirements based on business inputs
- **Live AI analysis** — Market Analysis, Expert Advice, and Competition sections generated by a real LLM call (Groq), with a static fallback so the app still runs with zero API setup
- **Server-side PDF reports** — compliance report generation via `reportlab` (also fixes a page-numbering bug present in the original client-side jsPDF version)
- **Verified static data** — license fees, timelines, and scheme links are hand-verified rather than LLM-generated, so users aren't shown hallucinated facts
- **Same design system** — Tailwind styling, colors, fonts, and layout carried over from the original React version, so the UI didn't regress during the rebuild

| Styling | Tailwind (build step) | Tailwind via CDN + same custom CSS classes |

## Setup & Running Locally

1. **Clone and open the project**
   ```bash
   git clone https://github.com/<your-username>/easebiz-ai.git
   cd easebiz-ai
   ```

2. **Create a virtual environment and install dependencies**
   ```bash
   python -m venv .venv
   source .venv/bin/activate      # on Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Set up your free LLM key (optional but recommended)**
   - Copy `.env.example` to `.env`
   - Get a free key (no credit card required) at [console.groq.com/keys](https://console.groq.com/keys) and set `GROQ_API_KEY=...` in `.env`
   - Without a key, the app still runs fully — it falls back to well-written static content instead of live-generated analysis

4. **Run the app**
   ```bash
   python app.py
   ```

5. Open **http://127.0.0.1:5000** in your browser.

## Deployment

This is a standard Flask app and runs anywhere Python does (Render, Railway, PythonAnywhere, Fly.io, or a VPS). For production, run it behind gunicorn instead of the Flask dev server:

```bash
pip install gunicorn
gunicorn -w 2 -b 0.0.0.0:8000 app:app
```

Set `GROQ_API_KEY` and `FLASK_SECRET_KEY` as real environment variables on your host — don't rely on the `.env` file in production. A `.gitignore` is included so `.venv/` and `.env` never get committed.
